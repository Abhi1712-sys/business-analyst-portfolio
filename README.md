Sales & Operations Performance Dashboard

Hi! I'm a beginner in Business Analytics, and this is one of my first practical projects using Microsoft Excel.

I created this small dashboard using a sample retail sales dataset to practise analysing business data and presenting insights in a simple visual format.

What I worked on
- Calculated key performance indicators (KPIs), including total revenue, orders, units sold and average order value.
- Analysed revenue across different regions and products.
- Reviewed delivery performance and identified delayed orders.
- Created charts, PivotTables and interactive slicers.
- Added a few business insights and recommendations based on the results.

Key findings
- Total revenue: **$13,375**
- Total orders: **12**
- Highest-revenue region: **Auckland**
- Highest-revenue product: **Laptop**
- Delivery delay rate: **58.33%**

Tools used
- Microsoft Excel

This is a small learning project, not a professional or real-business analysis. I'm using projects like this to improve my Excel, data analysis and business problem-solving skills as I continue learning Business Analytics.

I'm looking forward to building more projects and improving with every step!
